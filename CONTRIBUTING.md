# Contribuindo

1. Abra uma issue descrevendo o problema, extensão ou experimento.
2. Crie uma branch específica.
3. Preserve a formulação matemática e acrescente testes/checkpoints quando alterar o código.
4. Execute `python -m compileall src scripts tests` e, quando possível, `python scripts/verify_results.py`.
5. Envie um pull request com descrição da alteração e do impacto sobre a reprodução.
